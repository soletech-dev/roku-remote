# Roku Remote v1.0

A Python CLI remote controller for Roku devices using the Roku HTTP API.

## Features

- Home button
- Volume control
- Navigation controls
- Launch YouTube and Netflix
- Power on/off
- Connection status check

## Requirements

Python 3

Install:

pip install requests colorful

## Usage

Run:

python roku_remote_v1.py

Enter your Roku IP address when requested.
